# Aula 01 — Introdução à Virtualização e Instalação do Ubuntu Server

## Objetivo

Compreender os conceitos básicos de virtualização, criar uma máquina virtual utilizando o VirtualBox e realizar a instalação do Ubuntu Server.

## Ferramentas utilizadas

- Oracle VirtualBox
- Ubuntu Server
- Windows (sistema hospedeiro)

## Configurações previstas da máquina virtual

| Recurso | Configuração |
|---|---|
| Nome | ubuntu_server |
| Sistema operacional | Ubuntu Server |
| Memória RAM | 1,5 GB inicialmente, com redução prevista para 768 MB |
| Processador | 1 CPU |
| Disco virtual | 32 GB |
| Formato do disco | VDI |
| Armazenamento | Dinamicamente alocado |

## Desenvolvimento

A atividade foi iniciada no laboratório do IFAL, com a preparação do ambiente e a configuração inicial da máquina virtual no VirtualBox.

Durante a tentativa de selecionar a imagem ISO do Ubuntu Server, foram encontradas dificuldades para localizar o arquivo solicitado e acessar o servidor de arquivos da rede.

## Situação da atividade

Instalação do Ubuntu Server ainda pendente de conclusão.

## Próximas etapas

- Selecionar uma imagem ISO compatível.
- Realizar a instalação com o particionamento solicitado.
- Configurar o usuário administrador e o serviço SSH.
- Executar o comando `sudo apt-get update`.
- Registrar evidências da instalação concluída.
